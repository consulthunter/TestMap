# Analysis

This project is for analysis of software testing data provided by the output TestMap.

Why make a separate project for this?

C# doesn't really have a comprehensive statistical library like python.

The current open source statistical libraries for C# are not enough.

It looks like the only comprehensive statistical library for C# is paid and not open source.

Why don't you use python executed from within C#?

I thought that would be messy. Don't like the idea of calling a python script from within C#.

## Usage

Basically, the idea is to install the analysis package and run the scripts.

The scripts could combine, clean, and analyze the data.

The notebooks would provide some visualization and other functions.
